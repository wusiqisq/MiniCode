## 当前任务

目标：实现可安装、可启动、可交互并正常退出的最小终端程序。

验收条件：

- 独立虚拟环境中可以安装项目，`python -m minicode` 可以启动。
- 普通输入得到模型尚未接入的提示，并继续等待；空白输入被跳过。
- `/exit`、EOF 和 Ctrl+C 正常退出，不显示异常堆栈。
- 对应自动化测试通过，测试不需要网络或密钥。
- README 提供经过实际验证的安装、启动和测试命令。

完成内容：

- `pyproject.toml`：声明 Python 3.11+、setuptools 构建配置和 pytest 开发依赖；无第三方运行依赖。
- `src/minicode/__main__.py` 调用 `cli.main()`；`cli.py` 负责输入循环、占位回复及退出处理。
- `tests/test_cli.py`：模拟输入验证交互分支，并从项目以外的临时目录以子进程验证已安装的模块入口。
- README 补充当前能力、安装、启动、测试和代码入口说明。

验证结果：

- 通过：`python3 -m venv .venv`、激活虚拟环境和 `python -m pip install -e '.[dev]'`，成功安装项目及测试依赖。
- 通过：`python -m pytest`，10 项测试通过，覆盖普通输入后继续等待、空白、退出命令、EOF、Ctrl+C 和模块启动。
- 通过：实际终端执行 `python -m minicode`，普通输入显示占位回复，空白输入跳过，Ctrl+C 显示简短提示并以退出码 0 结束，无异常堆栈。
- 通过：`git diff --check`；检查新增文件和 Git 忽略规则，虚拟环境、缓存和包元数据未进入待提交文件。
- 未执行：其他 Python 版本的兼容性测试；当前仅实际验证 Python 3.12.3。
- 未执行：真实模型 API 验证，本阶段尚未接入模型。
